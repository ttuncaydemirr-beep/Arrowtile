# Play sürüm notları

`release.yml` (Release AAB), "release_notes_*" girdileri boşsa bu klasördeki dosyaları Play'e "Yenilikler" olarak gönderir.
Her yüklemeden önce metinleri yeni sürüme göre güncelleyin (en çok **500 karakter**, düz metin):

| Dosya | Play dili |
|---|---|
| `tr.txt` | tr-TR |
| `en.txt` | en-US |
| `de.txt` | de-DE |
| `ar.txt` | ar |
