# CoachBubble
Öğretici adımlarında tahtanın üstünde duran ipucu balonu.

**Tüketicinin sağladığı:** kısa açıklama + isteğe bağlı "Atla" (`.at-btn.tiny`).
- `ink` dolgu, `bg` yazı, `radius-tool`, `float` gölgesi. Tahtanın 8 px altında, yanlardan 16 px içeride.
- Büyük tahtada `.pass` ile dokunuşlar alttaki tahtaya geçer; yalnızca düğme tıklanabilir.
