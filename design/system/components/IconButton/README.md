# IconButton
48 × 48 px kare, yalnızca simgeli düğme; üst çubukta geri ve duraklat için.

**Tüketicinin sağladığı:** `<button class="at-icon-btn" aria-label="…">` içinde tek `.at-ic`. `aria-label` zorunlu.

- `card` dolgu, `radius-btn`, `raise-3`; basılı hali `Button` ile aynı.
- Geri oku RTL'de aynalanır: simgeye `at-flip-rtl` ekleyin. Oynat/duraklat aynalanmaz.
- Devre dışı (takvimde gelecek ay): %35 opaklık.
