# ShopItem
Mağazada bir ok temasını önizleme tuvaliyle gösteren kart.

**Tüketicinin sağladığı:** 88 × 64 px tuval (temanın oklarıyla çizilmiş mini tahta), ad, fiyat (jeton simgesi + sayı veya "Ücretsiz"), eylem düğmesi.
- `card` + `raise-3`, `radius-card`, 12 px dolgu, 2 sütunlu ızgara; düğme 2. sütunda, 48 px.
- Düğme durumu: `primary` "Satın al", `secondary` "Kuşan", `equipped` "Kuşanıldı"; jeton yetmiyorsa devre dışı.
