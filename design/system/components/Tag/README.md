# Tag
Kısa durum etiketleri: ödül etiketi, çip ve rahat mod rozeti.

**Tüketicinin sağladığı:** kısa metin (1–3 kelime).

- `.at-tag`: `star` dolgu, `on-gold` yazı (her temada sabit #22252B). Seviye sonu başarıları.
- `.at-tag.fast`: `star` %30 + `cell` karışımı, `ink` yazı.
- `.at-chip`: `cell` dolgu; günlük bulmaca istatistikleri.
- `.at-badge`: `card` + `raise-2`, `success` yazı + yaprak simgesi; rahat mod.
