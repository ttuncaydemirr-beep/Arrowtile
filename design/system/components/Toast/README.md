# Toast
Ekranın altında kısa süre görünen bildirim.

**Tüketicinin sağladığı:** tek cümle, olanı söyleyen metin ("Tema kuşanıldı", "Kod kopyalandı").
- Ters renk: `ink` dolgu, `bg` yazı; `radius-btn`, 700 ağırlık. Alttan 110 px + güvenli alan yukarıda, 200 ms kayarak belirir.
- Eylem düğmesi içermez; eylem gerekiyorsa `Sheet` kullanın.
